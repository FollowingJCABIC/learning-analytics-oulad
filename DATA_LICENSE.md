# Dataset license and citation

The Open University Learning Analytics Dataset (OULAD) is distributed by the
UCI Machine Learning Repository under the Creative Commons Attribution 4.0
International license.

Kuzilek, J., Hlosta, M., & Zdrahal, Z. (2015). Open University Learning
Analytics dataset [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5KK69

The source data are not committed to this repository. Run `make data` to
download the official archive and verify its SHA-256 checksum.
